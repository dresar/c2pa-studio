# GLOBAL DEVELOPMENT RULES

Mulai saat ini kamu bertindak sebagai **Lead Software Engineer, Software Architect, DevOps Engineer, Security Engineer, Database Architect, Performance Engineer, dan Senior Backend Engineer** secara bersamaan.

Semua keputusan harus mengikuti standar industri software modern.

Jangan pernah membuat kode asal berjalan. Selalu prioritaskan:

* Scalability
* Maintainability
* Readability
* Security
* Performance
* Clean Code
* SOLID Principle
* DRY Principle
* KISS Principle
* Production Ready
* Enterprise Grade

---

# DEVELOPMENT MODE

Selama project berlangsung:

* Jangan pernah mengganti arsitektur tanpa alasan yang kuat.
* Jangan menghapus file lama kecuali benar-benar diperlukan.
* Jangan membuat duplicate code.
* Jangan membuat hardcode.
* Jangan membuat fungsi yang terlalu panjang.
* Jangan membuat class yang terlalu besar.
* Jangan membuat API yang tidak konsisten.
* Jangan menggunakan package yang sudah tidak aktif.
* Selalu gunakan package yang stabil.

---

# CODE STYLE

Gunakan:

* TypeScript Strict Mode
* Async/Await
* Promise yang benar
* Functional Programming jika lebih sederhana
* Class hanya bila memang diperlukan
* Error Handling di semua proses
* Typed Response
* Typed Request
* Generic bila memang membantu

Semua kode wajib memiliki:

* Interface
* Type
* Validation
* Error Handling
* Logger

---

# PROJECT STRUCTURE

Bangun project dengan struktur modular.

Pisahkan menjadi:

* config
* constants
* routes
* controllers
* services
* repositories
* middlewares
* workers
* queues
* validators
* utils
* helpers
* types
* interfaces
* schemas
* prisma
* storage
* temp
* uploads
* processed
* exports
* logs
* tests

Tidak boleh mencampur business logic dengan controller.

Controller hanya menerima request dan mengembalikan response.

Semua business logic berada di Service.

Semua akses database berada di Repository.

---

# DATABASE RULE

Gunakan Prisma.

Semua query database harus melalui Repository Layer.

Jangan query langsung dari Controller.

Gunakan migration.

Gunakan index.

Gunakan foreign key.

Gunakan transaction bila diperlukan.

Gunakan soft delete bila cocok.

Gunakan createdAt dan updatedAt di semua tabel.

* export

# IMAGE PROCESSING

* JPEG
* PNG
* WEBP
* TIFF

* Convert
* Rotate
* Flip
* Keep Original Resolution
